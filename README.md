## Що робить проєкт

Проєкт демонструє роботу планувальника операційної системи реального часу FreeRTOS на базі емулятора Windows (WIN32-MSVC). У програмі створюються три негармонічні періодичні задачі (`MUVL_T1`, `MUVL_T2`, `MUVL_T3`), кожна з яких виконує активну імітацію обчислень (`busy-loop`) заданої тривалості та виводить у консоль часові мітки початку й завершення у системних тіках.

## Дослідження `configUSE_TIME_SLICING`

Для задач однакового пріоритету перевірено два режими роботи планувальника у файлі `FreeRTOSConfig.h`:
* **`configUSE_TIME_SLICING = 1`**: задачі рівного пріоритету отримують процесорний час по черзі кожен тік (алгоритм Round-Robin), що мінімізує затримку першого старту, але розтягує загальний час виконання кожної задачі.
* **`configUSE_TIME_SLICING = 0`**: активна задача не витісняється іншими задачами того ж пріоритету до моменту виклику `vTaskDelayUntil()`, через що збільшується джитер початку періоду для задач, які очікують у черзі.
